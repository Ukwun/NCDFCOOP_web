## 📞 DEPLOYMENT SUPPORT

### If Something Goes Wrong

**Build fails on Netlify:**
- Check: Environment variables are set correctly
- Solution: Copy all from `.env.local` to Netlify settings

**Site won't load:**
- Check: Netlify build logs
- Check: Firebase credentials active
- Solution: Restart build in Netlify dashboard

**Payment won't process:**
- Check: Flutterwave keys are correct
- Check: Test mode is active (for testing)
- Solution: Verify webhook URL in Flutterwave dashboard

**Database errors:**
- Check: Firestore rules allow read/write
- Check: Firebase project is active
- Solution: Review Firestore security rules
